# Test and calibration data: provenance

Every file in this directory, what it is, and what is **not** known about it.
Used by `ch_math` tests (`risk_stress.rs`, `move_guard_load.rs`), by
`services/risk` (calibration) and by the backtest ([`docs/BACKTEST.md`](../../../../docs/BACKTEST.md)).

| File | Source | Range (UTC) | Frequency | Rows | Licence |
| --- | --- | --- | --- | ---: | --- |
| `binance_nov2022_daily.csv` | Binance spot klines REST API, `data-api.binance.vision/api/v3/klines` (exact URL in the file header), symbols SOLUSDT and ETHUSDT. Columns: close and low only, in USDT | 2022-11-01 to 2022-11-18 | 1 day | 18 | **Unknown.** Not recorded at retrieval. |
| `klines_20m/SOLUSDT-2022-11.csv` | Binance public data archive `data.binance.vision`, monthly 1-minute spot klines, aggregated to 20-minute windows by `scripts/data/fetch_klines_20m.py` | 2022-11-01 00:00 to 2022-11-30 23:40 (window starts) | 20 min (from 1 min) | 2,160 | **Unknown.** Not recorded at retrieval. |
| `klines_20m/ETHUSDT-2022-11.csv` | same | same | 20 min | 2,160 | **Unknown.** |
| `klines_20m/SOLUSDT-2026-09.csv` | same | 2026-09-01 00:00 to 2026-09-30 23:40 | 20 min | 2,160 | **Unknown.** |
| `klines_20m/ETHUSDT-2026-09.csv` | same | same | 20 min | 2,160 | **Unknown.** |
| `vectors/portfolio.json` (in `../vectors/`) | Generated by this repository (`CH_UPDATE_VECTORS=1 cargo test -p ch_math --test vectors`) | — | — | — | Same as the repository |

Ranges and row counts were read back from the files with
`cd services/risk && npm run backtest` (the `inputs` block in
`docs/backtest/results.json`).

## Integrity

- `klines_20m/SOURCES.txt` lists the SHA-256 of each source archive. The
  fetch script verified each one against Binance's published `.CHECKSUM` file.
- SHA-256 of the committed CSVs, as used by the risk service and backtest, are
  recorded in `services/risk/params/calibration.json` and
  `docs/backtest/results.json` (`inputs`).

## What is not known

- **Licence.** Neither the files nor the fetch script record licence or
  terms of use. Binance publishes this data publicly, but this repository does
  not state the applicable terms. Check them before redistributing the files.
- **Retrieval date of the 20-minute files.** Not recorded. The files were
  first committed on 2026-10-12 (commit `68663f0`). That is the commit date,
  not the retrieval date.
- **Retrieval date of the daily file.** The file header says 2026-10-11. This
  repository has no other record of it.
- **Venue coverage.** Binance spot only: one venue, no perpetuals, no funding,
  no cross-venue basis. Basis parameters (`basis_bps`, `basis_decorr_ppm`)
  therefore **cannot** be estimated from this data, and the risk service keeps
  their current values and says so.

## Formats

- `binance_nov2022_daily.csv`: `#` comment lines, then
  `date,sol_close,sol_low,eth_close,eth_low` (decimal USDT).
- `klines_20m/*.csv`: `window_start_ms,open,high,low,close`, prices as integer
  micro-USD (1e6). A window is 20 minutes, about one credit lifetime
  (`credit_ttl_slots` ≤ 3,000 slots).
